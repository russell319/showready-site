Founding and early-adopter places

Places are claimed automatically when an account saves its first plan, profile or Film project. Accounts from before the offer (yours and the demo accounts) are marked internal and never count. To make another account internal, run in Supabase: update public.offer_places set tier = 'internal', place_no = null where owner = (select id from auth.users where email = 'their@email');
